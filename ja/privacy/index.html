プライバシーポリシー

最終更新日：2026年8月2日 · 対象アプリ：WiFi 侵入者アラート（パッケージ名 com.kizunasoftware.wifi_intruder_alerts）

Kizuna Software Solutionsでは、ユーザーのプライバシー保護に対する揺るぎないコミットメントのもと、「WiFi 侵入者アラート」アプリケーションを構築いたしました。本プライバシーポリシーは、当アプリケーションがお客様のデータとどのように相互作用するか、ネットワーク診断および境界セキュリティ機能を提供するためにどのような情報が処理されるか、そして当社がお客様のデジタルフットプリントをどのように保護するかについて説明するものです。

WiFi 侵入者アラートをインストールおよび利用することにより、お客様は本書に記載されているデータ慣行を認識し、これに同意したものとみなされます。本ポリシーは、透明性に対する当社の取り組みの不可欠な一部であり、当社の利用規約と並んで適用されます。

1.データ処理とコア機能

当社は厳格なデータ最小化の原則を遵守しています。リアルタイムのネットワークインサイトを提供し、不正なデバイスを検出し、ワイヤレス侵入の可能性を警告するために、本アプリケーションはローカルのネットワーク構成への運用上のアクセスを必要とします。

ローカル技術データ

安定した接続を確立し、境界分析を実行するために、本アプリケーションは以下のデータを処理します。

  • SSID（Service Set Identifier）：現在のワイヤレスネットワーク環境を識別し、カタログ化するために使用されます。
  • BSSID（Basic Service Set Identifier）：特定のハードウェアアクセスポイントを検出し、ローカルインフラストラクチャをマッピングするために使用されます。
  • IPアドレス（Internet Protocol Address）：ローカルデバイスの検出を調整し、ルーティングループをチェックし、レイテンシ診断を実行するために使用されます。

WiFi侵入者およびネットワークデバイス検出

未知のネットワーク参加者にフラグを立て、ハードウェアアセットを検証し、カスタムアクセスルールを構築するために、本アプリケーションはローカルエリアネットワーク（LAN）をスキャンします。このセキュリティ運用では、以下のデータが処理されます。

  • MACアドレス（Media Access Control Address）：ネットワークトポロジを介して通信する個々のハードウェアユニットを一意に識別するため、デバイス上で処理されます。
  • デバイスのホスト名および製造元のシグネチャ：生のハードウェア識別子を、人間が読めるデバイス名に変換するために分析されます（例：認識されていないスマートフォンとスマートサーモスタットの識別など）。
  • ユーザー定義の信頼プロファイル：デバイスを「検証済み」、「未検証」、または「侵入者」として明示的にマークするなどの、お客様による手動の分類を保存します。

ローカルファーストの原則

ローカルのネットワークシグネチャ、検出されたMACアドレス、およびユーザーが編集した「検証済み/未検証」のデバイスリストはすべて、お客様の物理デバイスのサンドボックス化されたローカルストレージ内でのみ処理および保存されます。この運用データが、外部のKizuna Software Solutionsの企業サーバーに送信、保存、または収集されることは決してありません。お客様の家庭内または企業内のネットワーク設計図は、厳格にお客様自身だけのものとして維持されます。

このローカル処理のみという原則に対する唯一の例外は、次のセクション2で説明するオプトイン機能「AIインサイト」です。AIインサイトを一度も有効にしなかった場合、本セクションで説明したネットワークまたはデバイスのデータが端末外に送信されることはありません。

2.AIインサイト（オプトイン機能）

WiFi 侵入者アラートには、デバイスの推定される種類、リスクスコア、または疑わしいなりすまし挙動について、わかりやすい自然言語の説明を生成するオプション機能「AIインサイト」が搭載されています。この機能は既定でオフになっており、設定画面で明示的に有効にした場合にのみ動作します。

AIインサイトを有効にすると、本アプリケーションは、現在表示しているデバイスまたはネットワークに関する限定的な情報（MACベンダー/製造元シグネチャ、ホスト名、IPアドレス、開いているポート、および端末上で既に算出されているリスク/信頼シグナルなど）を、サードパーティのAI推論プロバイダーであるGroq, Inc.に、暗号化された（HTTPS）接続を通じて送信します。これは自然言語の要約を生成する目的のみに使用されます。アカウント情報、個人を特定できる識別子、閲覧履歴、または端末上の他のアプリのデータがこの送信に含まれることは一切ありません。

AIインサイト機能はあくまで補助的な説明レイヤーであり、信頼ステータスを決定したり、数値のリスクスコアを算出したり、独自にデバイスをなりすましと判定したりすることはありません。これらの判定はすべて、お客様の端末上で動作する決定論的な（AIを用いない）ロジックによって行われ、AIはそのロジックが既に導き出した結論を説明するのみです。AIへのリクエストが何らかの理由で失敗した場合でも、本アプリケーションの他のすべての機能には影響しません。

AIインサイトはいつでも設定画面から無効にできます。無効にすると、この目的のための端末外へのデータ送信は直ちに停止します。

3.広告およびマーケティングポリシー

WiFi 侵入者アラートは完全に広告フリーです。当社はサードパーティの広告ブローカーと提携せず、商業バナーを表示せず、マーケティング指標のためにアプリケーション内での行動をプロファイリングすることもありません。したがって、本アプリケーションがお客様のデバイスのGoogle広告ID（AAID）を追跡、要求、または処理することはありません。

4.サードパーティサービス

当社は、サードパーティのソフトウェア開発キット（SDK）および外部サービスの利用を、アプリケーションの安定性のために排他的に必要なプラットフォームレベルのインフラストラクチャ、およびセクション2で説明したオプションのAIインサイトプロバイダーのみに制限しています。これらのプロバイダーのプライバシーフレームワークは、以下からご確認いただけます。

  • Google Play開発者サービス（Google Play Services）
  • Groq, Inc. — AIインサイト機能を有効にした場合のみ連絡されます

5.ログデータ

アプリケーションの予期せぬクラッシュやランタイムエラーが発生した場合、本アプリケーションはお客様のデバイスによって生成された診断用のクラッシュテレメトリ（安全なプラットフォームデバッグツール経由）を収集します。これはログデータと呼ばれ、以下が含まれます。

  • お客様のデバイスのモデル名、製造元、およびコアハードウェアアーキテクチャ。
  • 例外（エラー）が発生した正確な時点におけるオペレーティングシステムのバージョンおよびシステム状態の構成。
  • システムイベントに関連する実行メトリクス、タイムスタンプ、およびスタックトレース。

当社は、これらのログをソフトウェアのバグの特定、リソース割り当ての最適化、およびパフォーマンスアップデートの展開のためにのみ使用します。

6.ストレージとローカルデータベース

WiFi 侵入者アラートは、追跡用Cookieを使用しません。本アプリケーションは、デバイス固有のネイティブストレージメカニズム（暗号化されたSQLiteやプラットフォームのSharedPreferencesなど）を利用して、検証済みのデバイスプロファイル、侵入者フィルター、およびカスタム設定をローカルに保持します。

ストレージの権限は、モバイルオペレーティングシステムの設定からいつでも管理できます。システム設定からアプリケーションのキャッシュまたはデータを消去すると、ローカルに構築されたデバイス検証リストが恒久的に削除されますのでご注意ください。

8.セキュリティ

お客様のモバイルアプリケーション環境の防御的な整合性を確保することは、当社の最優先事項です。当社はローカルアプリケーションのデータベースおよびAIインサイトの通信経路を保護するために標準的な商用パターンを使用していますが、ウェブ上の送信やデジタルストレージアレイにおいて、完全に不変（絶対に変造不可能）なものは存在しません。当社はローカルの暗号化フレームワークを定期的に評価していますが、新たに出現するすべてのデジタル脅威に対する絶対的なセキュリティを保証することはできません。
